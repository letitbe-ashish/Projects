# Customer Segmentation using Clustering

A machine learning project that segments mall customers into distinct groups based on **Age**, **Annual Income**, and **Spending Score** using various unsupervised clustering algorithms. Includes an interactive **Streamlit web app** for real-time customer segment prediction.

---

## Project Structure

```
├── Customer_Segmentation_Final.ipynb  # EDA, clustering models, evaluation
├── app.py                             # Streamlit prediction app
├── Mall_Customers.csv                 # Raw dataset
├── kmeans_model.pkl                   # Saved K-Means model (generated by notebook)
├── scaler.pkl                         # Saved StandardScaler (generated by notebook)
├── cluster_insights.csv               # Segment metadata (generated by notebook)
├── requirements.txt
└── README.md
```

---

## Dataset

**Mall_Customers.csv** — 200 mall customer records with the following columns:

| Column | Description |
|---|---|
| `CustomerID` | Unique identifier |
| `Genre` | Gender (Male / Female) |
| `Age` | Customer age |
| `Annual Income (k$)` | Annual income in thousands of dollars |
| `Spending Score (1-100)` | Mall-assigned spending score |

---

## Algorithms Compared

| Algorithm | Features Used | Clusters |
|---|---|---|
| K-Means | Age, Income, Spending (3 features) | 6 |
| K-Means | Income, Spending (2 features) | 5 |
| K-Means + PCA | 2 PCA components | 6 |
| Agglomerative Clustering | All 3 features | 6 |
| Bisecting K-Means (Divisive) | All 3 features | 6 |
| DBSCAN | All 3 features | Auto-detected |

Models are evaluated using **Silhouette Score** and **Davies-Bouldin Score**.

## Setup & Installation

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd customer-segmentation
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Notebook

Open `Customer_Segmentation_Final.ipynb` in Jupyter to train models and generate the required files:

```bash
jupyter notebook Customer_Segmentation_Final.ipynb
```

Running all cells will produce:
- `kmeans_model.pkl`
- `scaler.pkl`
- `cluster_insights.csv`

### 4. Launch the Streamlit App

```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`.

---

## Streamlit App

The web app allows you to input a customer's **Age**, **Annual Income**, and **Spending Score** and instantly predicts which segment they belong to.

It also displays a full table of all 6 customer segments with their characteristics.

> **Note:** `kmeans_model.pkl`, `scaler.pkl`, and `cluster_insights.csv` must be present in the same directory as `app.py` before launching the app.
